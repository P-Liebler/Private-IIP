# P3 FX data

Manual CSV accepts positive dated CHF, EUR and USD pairs with explicit base, quote and rate. `fx_rates` holds the selected rate; `fx_rate_versions` keeps its source, raw reference, local timestamps and rule versions. `GET /api/v1/fx/rate` returns direct, inverse or one-bridge cross rates, with the contributing version IDs, rate dates and sources. Same-currency conversion is an explicit derived identity rate. A missing rate returns `UNAVAILABLE`, never zero.

Carry forward is limited to `FX_MAX_CARRY_DAYS` calendar days (default 5, configurable 0–10). The response exposes `rate_date`, `carry_days`, `carried_forward` and conversion direction. Each leg of a cross must separately meet that limit and `as_of` visibility. This is a local calendar-day policy; a market-specific holiday calendar and fixing-time proof are future refinements, so a date alone is not evidence of a specific intraday availability time.

The ECB collector implements the documented daily `EXR/D.CHF+USD.EUR.SP00.A` SDMX CSV series. PR1 adds bounded windows, conditional requests and durable sync state. It checks rights and Valkey before each request, stores exact response bytes before parsing, verifies dimensions and reuses the FX version service. Cross-source conflicts enter quarantine. It stays disabled until an operator documents rights and enables it; tests use offline transports.

PR1 implements the verified monthly SNB `devkum` EUR/CHF and USD/CHF reference contracts and `snboffzisa` policy rate as versioned **macro observations**. Monthly averages never enter daily valuation FX. A daily SNB parser remains unavailable. Conditional ETags preserve the last parsed response on 304 and update operational success without changing canonical knowledge times. Sources checked 2026-10-16: [SNB API](https://data.snb.ch/en/help_api), [ECB API](https://data.ecb.europa.eu/help/api/data), [rights matrix](../data/SOURCE_RIGHTS_MATRIX.md).
