# Portfolio Performance (P4)

All return inputs come from complete historical portfolio valuations using raw accepted closes plus explicitly applied corporate actions. A day with missing or stale prices, missing current FX or unresolved eligible actions makes period return `DATA_UNAVAILABLE`. No daily return is calculated from a known subtotal.

- **Absolute return (base currency):** ending value minus opening value minus net external deposits/withdrawals. Fees, taxes, dividends and trading effects remain inside the value change. External flows are translated at their dated P3 FX rate.
- **TWR:** each daily factor is `(ending value - end-of-day external flow) / previous closing value`; factors are geometrically linked. Zero or negative opening capital has no defined factor. A first funding flow from zero starts the invested history without manufacturing a return.
- **XIRR:** external contributions are negative investor cash flows, withdrawals positive, and terminal portfolio value positive. Calendar day differences use 365.2425 days/year. The solver conservatively requires exactly one chronological sign change after grouping same-day flows, then brackets/bisects within -99.99% to 100000%. Non-conventional flows, no supported root or numerical failure yield null.
- **CAGR:** annualized linked TWR over actual calendar days when the linked factor is positive; null for zero-length periods or undefined TWR.
- **FX contribution:** sum over days of prior close native cash and security exposures multiplied by that day's FX-rate change. It is an opening-exposure translation component in base currency; trades and same-day cash flows do not enter that day's FX exposure. Missing required dated FX makes this component null.

The API offers daily, weekly and monthly points. Daily calculations still occur for weekly/monthly output so TWR remains geometrically linked. `as_of` is a timezone-aware knowledge cutoff; later imported corrections are excluded when asking what was known earlier. Historical data availability begins with its real import, not an inferred historic snapshot. Snapshots can be rebuilt after corrections and carry an input hash.

Benchmarks are linked to real instrument price versions. Endpoint prices may carry at most seven calendar days. One opening share is adjusted by explicit canonical splits; gross dividends accumulate as non-reinvested base-currency cash using event-date P3 FX. Start/end instrument values use their dated P3 FX. The response includes price/action version IDs, dates and methodology. Missing prices or any required FX yields `DATA_UNAVAILABLE`; delisting needs settlement review. Benchmark and portfolio returns remain explicitly `PROVISIONAL` with `action_coverage=UNVERIFIED` until coverage can be attested independently.

`/summary` supplies daily, lifetime and YTD absolute base-currency returns, net of dated external flows. Daily compares the previous calendar close; YTD compares December 31. Missing opening/current valuation or event FX leaves the affected amount null. Dashboard totals are grouped by portfolio base currency and use backend Decimal arithmetic. Different base currencies are displayed separately; a partial group retains only a labelled known subtotal.
