# CycloneDX schema sources

Unmodified schema files from `https://cyclonedx.org/schema/`: bom-1.7, SPDX,
JSF 0.82 and cryptography definitions. Retrieved for PR4 and checked on 20.10.2026.
The accompanying upstream LICENSE is retained. `validate_sboms.py` resolves all
references from these files offline and records their SHA-256 hashes.

Source: https://github.com/CycloneDX/specification
